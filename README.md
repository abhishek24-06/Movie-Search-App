# Angular Movie Search Application

A simple Angular application that allows users to search through a collection of movies.

## Features

- Display list of movies
- Search functionality to filter movies by title
- Responsive design with card layout

## Development Setup

1. Clone the repository
2. Run `npm install` to install dependencies
3. Run `ng serve` for a dev server
4. Navigate to `http://localhost:4200/`

## Technologies Used

- Angular
- TypeScript
- CSS Grid & Flexbox
